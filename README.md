# Task Tracker

A C# console application for managing tasks.

## Features

- Creating new tasks.
- Viewing the list of tasks.
- Modifying task descriptions.
- Deleting tasks.
- Tracking the completion status.
- Saving tasks to a JSON file.

## Technologies

- C#
- .NET
- System.Text.Json
- Git / GitHub

## Running the project

1. Clone the repository:
 ```bash
 git clone https://github.com/vivienne159/TaskTracker.git
 ```
2. Go to the project folder:
 ```bash
 cd Task_trecker
 ```
3. Run the application:
 ```bash
 dotnet run --project Task_trecker
 ```
